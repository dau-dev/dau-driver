Register map 0.2: OPERATOR_BITMAP is hardware truth (typed INT32 at register level, no five-type expansion) and HOST_OPCODE_BITMAP carries the host-computed opcodes (AVERAGE = SUM/COUNT divide) separately.

MAGIC reads, so the path is healthy, but the operator word is all-ones. Read literally that word claims every opcode the encoding has a bit for — including AVERAGE, which is host-computed and must never be submitted to a device. Silence is the only honest decode.
