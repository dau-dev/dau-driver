dau_driver.testing¶

Shared test doubles for DAU driver consumers.

Used by the dau-driver, dau, and dau-polars test suites so the fake device’s semantics cannot drift between packages. Not imported by production code.

class dau_driver.testing.FakeTransport[source]¶

In-memory DeviceTransport: records DMA traffic and register writes.

Advertises a current (register map 0.3) shell by default, including the job capacity a host batches against — an all-zero register file models a shell nobody builds any more, and every job test would be exercising the not-advertised refusal instead of the path it means to test. Tests that want an older shell clear or lower these.
