## Pre-requisites

You need Python >=3.10 on your machine to install `dau-driver`.

## Install with `pip`

```bash
pip install dau-driver
```

## Install with `conda`

```bash
conda install dau-driver --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `dau-driver` from source](Build-from-Source).
