dau_driver
==========

.. py:module:: dau_driver

.. autoapi-nested-parse::

   dau-driver: host I/O for a DAU device.

   Exports load on first use (:mod:`dau_driver._lazy`), so importing this
   package does not import ccflow and its stack before a caller asks for a
   name that needs it.

.. py:function:: lazy_exports(package: str, exports: dict[str, tuple[str, ...]]) -> tuple[collections.abc.Callable[[str], object], list[str]]

   A module ``__getattr__`` and ``__all__`` for ``{submodule: names}``.

   Returns both so the two cannot disagree: a name exported by nothing is
   not reachable, and a name declared here and missing from its submodule
   raises on first access rather than at import -- which is what the
   package's lazy-export guard test turns back into an import-time error.
